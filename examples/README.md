# A five-minute colour study

Start Pigment using the [README quickstart](../README.md#run-locally). This example contains invented pink, blue and yellow-gold colours, no personal image or paint selections.

1. Choose **Restore backup** (the restore control at the bottom of the page) and open [pink-blue-gold.json](pink-blue-gold.json). Expect three swatches: `#BF668C`, `#2255AA`, `#EEDC38`.
2. Select the pink, choose **Adjust colour**, enter `#C73532` in **Hex colour**, then **Apply colour**. Only the pink changes.
3. **Lock palette** and **Develop this colour**. Choose its core role and a shadow or highlight. Keep a manual choice while moving tonal spread; that manual tone should stay fixed.
4. **Find paint matches**, filter if useful and choose a bottle. The next target appears automatically; revisit through **Previous/Next** or the direct colour/shade list.
5. Give the study a name and **Save study**. Use **Preview card**, **Print PDF** and **Backup**. The card is one portrait A4 side with clear swatches and paint labels. This colour-only example has a proportional colour banner; upload your own image to try draggable framing.
6. Reload and open the saved study through **My studies**. Restore the downloaded backup in another browser if you want to transfer it.

Printing at Actual size is separate from judging physical colour. Use the printer proof to check scale/settings; printer/paper/paint accuracy remains an approximation. Keep personal study files out of public issues and source control.

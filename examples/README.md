# Try one painting study

1. Start the app and choose **Restore backup** in the footer.
2. Select `pink-blue-gold.json` from this folder. It is synthetic data with no uploaded image or personal information.
3. Select the pink swatch, choose **Adjust colour**, and move Hue to **25°**. Blue and gold stay unchanged. Select **Apply colour**.
4. Select **Lock palette**, then **Develop this colour** under the red swatch.
5. Select **Find paint matches**. Under **Extended palette**, select its Shadow, Midtone and Highlight in turn and choose a paint for each.
6. Save the study, export its reference card and download a backup. Reload, then reopen it from **My schemes**.

Expected result: three core colours with a red core, an independent shading sequence, named paints for its shades, and a portable backup. Paint suggestions are digital approximations, not mixing recipes.

# Security reports

Do not post secrets, private images or backups in a public issue. Use GitHub’s **Security → Report a vulnerability** option if the repository owner has enabled it. If it is unavailable, ask the maintainer in an issue to establish a private channel without disclosing the vulnerability details. Private reporting is not claimed to be enabled by this file.

This is a browser-local application. Keep Node.js and dependencies updated, and serve development builds only on the default loopback address. Static public hosting should use HTTPS. Imported backups are validated, but avoid opening files from untrusted sources unnecessarily.

Report the affected version, reproduction steps and expected versus observed behavior. No response-time or supported-version guarantee is offered for this experimental project.
